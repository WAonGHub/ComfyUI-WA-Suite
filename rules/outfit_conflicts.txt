# QUICK SYNTAX GUIDE:
#   1. Pattern Matching:
#      - Exact tag     : `open shirt`     (matches exact tag, ignores `_` vs space & `(tag:1.2)` weights)
#      - Word match `~`: `~bra`           (matches any tag containing the whole word `bra`, e.g. `white lace bra`,
#                                          NEVER matches `braid`, `bracelet`, `braless`, or `no bra`!)
#      - Wildcard `*`  : `*skirt`         (character wildcard: matches `skirt`, `miniskirt`, `pleated miniskirt`)
#      - Group exclude : `-skirt lift`    (inside `@group`, vetoes non-garment action/modifier tags)
#
#   2. Definitions:
#      @view  <NAME> = pattern1, pattern2, ...      (if none match in prompt, defaults to `FRONT`)
#      @group <NAME> = pattern1, -exclude1, ...     (reusable group of garments or reveal modifiers)
#
#   3. Rules (evaluated in 2 stages — Occlusion FIRST, Combos SECOND!):
#      - Stage 1 (Occlusion & Rewrites):
#          HIDE <targets>                  | WHEN <cond> | VIEW <views> | UNLESS <cond> | +NEG <neg_tags>
#          REPLACE <targets> => <new_tag>  | WHEN <cond> | VIEW <views> | UNLESS <cond> | +NEG <neg_tags>
#      - Stage 2 (Visible-Only Overlaps — runs AFTER Stage 1 so hidden items never trigger combos!):
#          COMBO <itemA> + <itemB> => <combo_tag> | VIEW <views> | UNLESS <cond> | PLACEHOLDER /*...*/
#      - Stage 3 (Conditional Negative Reinforcements):
#          NEG <neg_tags>                  | WHEN <cond> | VIEW <views> | UNLESS <cond>
#
#   4. Condition Logic in `WHEN` and `UNLESS`:
#      - Comma `,` = OR   (e.g. `WHEN TOPS, DRESSES`)
#      - Plus  `+` = AND  (e.g. `UNLESS sitting + ~spread legs`)
#      - Bang  `!` = NOT  (e.g. `VIEW !BACK`)
# ==============================================================================


# ------------------------------------------------------------------------------
# 1. CAMERA PERSPECTIVES (`@view`)
# ------------------------------------------------------------------------------
# Multiple views can be active simultaneously (e.g. `from behind, from below` = BACK + BELOW).
# When no `@view` tag is found in the prompt, `FRONT` is assumed automatically.

@view BACK  = from behind, facing away, facing back, rear view, back view, ass focus
@view BELOW = from below, upskirt, low angle, worm's-eye view
@view ABOVE = from above, high angle, bird's-eye view
@view SIDE  = from side, profile
@view FRONT = from front, straight-on, facing viewer


# ------------------------------------------------------------------------------
# 2. REVEAL / STATE MODIFIERS (`@group`)
# ------------------------------------------------------------------------------
# Front-opening tops/dresses/robes reveal inner chest layers from FRONT / SIDE / ABOVE, NOT from BACK:
@group OPEN_FRONT   = ~open *shirt, ~open *blouse, ~open *dress, ~open *hanfu, ~open *aoqun, ~unbuttoned *aoqun, ~open *ruqun, ~open *kimono, ~open *yukata, ~open *robe, ~open *haori, ~open *sweater, ~open *cardigan, ~open *jacket, ~open *coat, ~open *blazer, ~open clothes, ~unbuttoned, ~partially unbuttoned, ~unzipped, front zipper, plunging neckline, ~cleavage, ~breasts out, ~breast slip, ~nipple slip, clothes pull, shirt pull, dress pull, hanfu pull, aoqun pull, ruqun pull, kimono pull, -~unzipped pants, -~unzipped shorts, -~unzipped jeans, -~unzipped skirt, -~unbuttoned pants, -~unbuttoned shorts

# Back-opening garments reveal inner back/straps/wraps from BACK:
@group OPEN_BACK    = ~backless, ~open back, virgin killer sweater

# All-angle upper reveals (visible from FRONT, SIDE, and BACK):
@group TOP_REVEAL   = ~shirt lift, ~sweater lift, ~dress lift, ~hanfu lift, ~aoqun lift, ~ruqun lift, ~kimono lift, ~clothes lift, ~lifting own clothes, ~torn, ~ripped, ~see-through, ~sheer, ~wet shirt, ~wet clothes, ~transparent, ~off shoulder, ~bare shoulders, ~strap slip, ~undressing, ~mirror, ~reflection

# Closed heavy outerwear (hides inner torso layers if neither jacket nor top is open):
@group CLOSED_OUTER = closed jacket, closed coat, closed blazer, closed cardigan, closed haori, closed robe, buttoned coat, zipped jacket

# Skirt / Dress / Hanfu / Aoqun / Kimono lower reveals (when panties under a skirt/dress/robe ARE visible):
@group SKIRT_REVEAL = ~skirt lift, ~dress lift, ~hanfu lift, ~aoqun lift, ~ruqun lift, ~mamianqun lift, ~kimono lift, ~clothes lift, ~lifting own clothes, ~upskirt, ~pantyshot, ~wind lift, ~skirt flip, ~skirt pull, ~skirt tug, ~skirt hold, ~skirt aside, ~dress pull, ~dress tug, ~dress aside, ~hanfu pull, ~hanfu aside, ~aoqun pull, ~aoqun aside, ~ruqun pull, ~ruqun aside, ~kimono pull, ~kimono aside, ~panties aside, ~panty pull, ~panties around one leg, ~see-through, ~sheer, ~torn skirt, ~torn dress, ~torn hanfu, ~torn aoqun, ~torn ruqun, ~torn kimono, ass visible through thighs, ~mirror

# Shorts / Pants lower reveals (when panties under pants/shorts ARE visible):
@group PANTS_REVEAL = ~pants pull, ~shorts pull, ~pants down, ~shorts down, ~pants around one leg, ~shorts around one leg, ~shorts aside, ~pants aside, ~unbuttoned pants, ~unbuttoned shorts, ~unzipped pants, ~unzipped shorts, ~unzipped jeans, ~open belt, ~open fly, ~whale tail, ~panties peek, ~lowleg pants, ~torn pants, ~torn shorts


# ------------------------------------------------------------------------------
# 3. GARMENT LAYER GROUPS (`@group`)
# ------------------------------------------------------------------------------
@group STD_BRAS  = ~bra, ~bikini top, ~bandeau, ~bustier, -~no bra, -~braless
@group SARASHI   = ~chest sarashi, ~sarashi, -~pelvic sarashi, -~no sarashi
@group BRAS      = STD_BRAS, SARASHI

@group TOPS      = ~shirt, ~sweatshirt, ~undershirt, ~overshirt, ~nightshirt, ~blouse, ~sweater, ~turtleneck, ~hoodie, ~jersey, ~camisole, ~tank top, ~crop top, ~tube top, -~no shirt, -~shirtless, -~shirt lift, -~sweater lift, -~clothes lift, -~shirt pull, -~shirt tug, -~holding shirt, -~shirt dress, -~shirtdress

@group OUTERWEAR = ~jacket, ~blazer, ~coat, ~cardigan, ~haori, -~no jacket, -~no coat, -~no haori

@group PANTS     = ~pants, ~jeans, ~trousers, ~shorts, ~bloomers, ~leggings, ~bike shorts, -~no pants, -~no shorts, -~under skirt, -~under dress, -~pants pull, -~shorts pull, -~pants down, -~shorts down, -~pants around one leg, -~shorts around one leg, -~shorts aside, -~pants aside


# ==============================================================================
# STAGE 1: DIRECTIONAL & LAYER OCCLUSION RULES (`HIDE` / `REPLACE`)
# ==============================================================================

# --- A. Upper Body: Bra & Chest Sarashi vs Shirt / Sweater / Dress / Hanfu / Aoqun / Kimono ---
# 1. From BEHIND: An `open shirt`, `open hanfu`, or `open aoqun` front does NOT show the bra or chest sarashi through the back!
#    Hide inner chest layers unless backless (`OPEN_BACK`) or lifted/sheer/off-shoulder (`TOP_REVEAL`), and push matching negatives so LoRAs don't draw straps/wraps over the back.
HIDE STD_BRAS | WHEN TOPS, DRESSES, OUTERWEAR | VIEW BACK | UNLESS OPEN_BACK, TOP_REVEAL | +NEG bra, bra straps
HIDE SARASHI  | WHEN TOPS, DRESSES, OUTERWEAR | VIEW BACK | UNLESS OPEN_BACK, TOP_REVEAL | +NEG sarashi, chest sarashi

# 2. From BEHIND: Clean up front-only torso tags (`open shirt`, `open hanfu`, `open aoqun`, `cleavage`, `unbuttoned`) so the model doesn't
#    hallucinate a front collar on the spine or twist the character backward when clothed from behind.
REPLACE ~open *shirt, ~unbuttoned *shirt   => shirt   | WHEN TOPS      | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *blouse, ~unbuttoned *blouse => blouse  | WHEN TOPS      | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *dress                       => dress   | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *hanfu                       => hanfu   | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *aoqun, ~unbuttoned *aoqun   => aoqun   | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *ruqun                       => ruqun   | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *kimono                      => kimono  | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *yukata                      => yukata  | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *robe                        => robe    | WHEN DRESSES   | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *sweater                     => sweater | WHEN TOPS      | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
REPLACE ~open *haori                       => haori   | WHEN OUTERWEAR | VIEW BACK | UNLESS FRONT, SIDE, OPEN_BACK, TOP_REVEAL
HIDE ~cleavage, unbuttoned, partially unbuttoned, open clothes, front zipper, plunging neckline, ~breasts out, ~breast slip, ~nipple slip | WHEN TOPS, DRESSES, OUTERWEAR | VIEW BACK | UNLESS FRONT, SIDE, TOP_REVEAL

# 3. From FRONT / SIDE / ABOVE: Hide bra & chest sarashi under a closed top/dress/hanfu unless opened in front (`OPEN_FRONT`) or lifted/sheer (`TOP_REVEAL`).
HIDE BRAS | WHEN TOPS, DRESSES | VIEW !BACK | UNLESS OPEN_FRONT, TOP_REVEAL

# 4. Explicitly closed outerwear hides bra & chest sarashi even from front unless lifted/sheer:
HIDE BRAS | WHEN CLOSED_OUTER | VIEW ANY | UNLESS TOP_REVEAL

# 5. Chest sarashi wraps tightly over the bust, obscuring a regular bra if both situational nodes are left enabled:
HIDE STD_BRAS | WHEN SARASHI | VIEW ANY


# --- B. Lower Body: Panties vs Skirt / Dress / Hanfu / Pants / Shorts ---
# 6. Skirt, Dress, or Hanfu obscures Panties from normal angles unless lifted, viewed from below, upskirt, or seated with spread legs:
HIDE PANTIES | WHEN SKIRTS, DRESSES | VIEW ANY | UNLESS VIEW:BELOW, SKIRT_REVEAL, sitting + ~spread legs, squatting + ~spread legs, all fours + VIEW:BACK, bent over + VIEW:BACK

# 7. Pants / Shorts / Leggings obscure Panties from all angles unless pulled down/aside or peeking:
HIDE PANTIES | WHEN PANTS | VIEW ANY | UNLESS PANTS_REVEAL, unzipped + !OUTERWEAR


# ==============================================================================
# STAGE 2: VISIBLE-ONLY OVERLAPS & SYNERGIES (`COMBO`)
# ==============================================================================
# Evaluated AFTER Stage 1! If `panties` were hidden by a skirt in Rule 5, `PANTIES + LEGWEAR`
# automatically will NOT fire — eliminating the need for separate exclusion (`EX`) nodes!

# 1. Panties + Pantyhose / Tights -> `(panties under pantyhose:1.1)`
COMBO PANTIES + LEGWEAR => (panties under pantyhose:1.1) | UNLESS panties over pantyhose, ~panties around one leg | PLACEHOLDER /*panties under pantyhose, */

# 2. Pants / Shorts + Skirt -> `pants under skirt`
COMBO PANTS + SKIRTS    => pants under skirt             | PLACEHOLDER /*pants under skirt, */

# 3. Pants / Shorts + Dress -> `pants under dress`
COMBO PANTS + DRESSES   => pants under dress             | PLACEHOLDER /*pants under dress, */
